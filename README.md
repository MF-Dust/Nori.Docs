# Nori.Docs

Nori Desktop Pet 的用户文档仓库。

这里的内容以 [`MF-Dust/Nori.Desktop`](https://github.com/MF-Dust/Nori.Desktop) 当前实现和正式 Release 为依据，重点帮助普通用户完成下载安装、桌宠设置、AI 与语音配置、长期记忆、MCP、插件使用和常见问题排查。

## 当前版本口径

- 最新稳定版：**v1.3.0-Serika**
- 主要验收平台：**Windows x64**
- 当前同时提供：**Windows x64、Linux x64、macOS Apple Silicon** 发布包
- 发布包为 framework-dependent，需要系统安装对应运行时

## 文档入口

文档正文位于 [`docs/`](./docs/)：

- `docs/user-guide/`：面向普通用户的操作手册
- `docs/guide/`：功能说明与进阶使用
- `docs/operations/`：兼容性、排障与安全模式
- `docs/reference/`：需要进一步了解时使用的技术参考

## 内容原则

文档以实际可用功能为准。尚未发布、仍在实验、只存在于开发分支或没有用户入口的能力，不会写成已经可用的正式功能。

如发现文档与最新版 Nori Desktop 不一致，欢迎在本仓库提交 Issue 或 Pull Request。
