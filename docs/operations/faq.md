# 常见问题与故障排查

这页补充一些更具体的排障场景。日常问题也可以先看 [用户手册中的常见问题](../user-guide/troubleshooting-and-faq.md)。

## Nori 双击后没有窗口

Windows 正式版应运行解压目录最外层的：

```text
Nori.exe
```

当前 2.x 正式包需要 **.NET Runtime 10**。WebView2 已不再是 Nori 原生主界面的运行依赖。

发布包内部的 `.current` 与 `app-*` 由最外层启动入口管理，不需要手动进入内部目录运行 `Nori.Desktop.exe`。

## 启动后一直停在加载界面

可以先用安全模式：

```powershell
.\Nori.exe --safe-mode
```

进入可用界面后，再检查最近修改过的 AI、语音、MCP、插件或模型设置。

## 桌面伴侣无法点击穿透

需要区分平台：

- Windows 支持模型区域与透明区域的点击穿透处理。
- Linux X11 可以使用窗口输入区域。
- Wayland 受协议能力限制，可能退化为整窗可点击。
- macOS 使用系统对应的鼠标忽略能力。

详情见 [跨平台支持与能力差异](./platform-matrix.md)。

## 导入 Live2D 模型后无法显示

先确认模型目录中有有效的 `*.model3.json`、对应的 `.moc3` 和纹理文件。

更推荐从模型管理页面使用本地导入，让 Nori 自己完成路径和文件结构检查。当前没有远程模型市场或自动下载器。

## AI 对话提示网络或认证错误

先到 **设置 → AI** 使用连接测试。

常见原因包括：

- 访问凭据失效
- Base URL 填写错误
- 模型名不可用
- 本地服务没有启动
- 网络环境无法访问目标服务

## 收到回复但没有语音

当前语音播放走原生音频后端，不依赖网页播放器。

TTS 可以使用 OpenAI、Gemini、MiniMax、IndexTTS-2、GPT-SoVITS 或 Custom HTTP；语音识别使用 Whisper。

如果自建 TTS 返回 MP3/OGG 而不是 WAV，当前播放会失败。

## 插件为什么没有自定义页面

当前 Plugin API 2.0 主要开放插件动作，让 AI 调用受信任的本机扩展。

宿主暂时没有开放第三方插件窗口、WebView 页面或聊天卡片。看到旧教程里这类描述时，以当前文档为准。

## 数据应该备份哪里

当前数据统一位于：

```text
<Nori 程序根目录>/data/
```

更新或搬家时保留这个目录即可。需要完整保留启动入口和版本槽时，直接备份整套 Nori 根目录更简单。

## 跨系统迁移后为什么有些凭据需要重填

敏感配置使用 `nsec2:` AES-256-GCM，并由各平台的安全存储保护主密钥。

旧 Windows 版本留下的 `enc:dpapi:` 密文无法直接在 macOS 或 Linux 解密时，需要重新填写对应凭据。普通聊天、记忆和模型数据不会因为这一点自动被删除。

## 怎样提交 Bug

在设置中导出脱敏诊断信息后，可以前往 [Nori.Desktop Issues](https://github.com/MF-Dust/Nori.Desktop/issues) 提交问题。

附上复现步骤、系统版本和诊断 ZIP，通常比直接上传整个数据目录更容易定位问题。
