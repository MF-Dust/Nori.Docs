# 语音交互与口型同步

Nori 可以朗读回复，也可以通过麦克风把语音转换成文字。语音播放时，桌面 Live2D 会根据实际音量同步嘴形。

## 当前支持的语音方式

在 **设置 → 语音** 中，当前 TTS 可以选择：

- **OpenAI**
- **Gemini**
- **MiniMax**
- **Custom HTTP**
- **GPT-SoVITS**

语音识别使用 **Whisper 接口**。

旧版的浏览器 Web Speech 与 Edge TTS 路径已经停用。如果检测到旧配置，Nori 会提示迁移到当前支持的语音提供商。

## 配置 TTS

不同提供商需要填写的内容会略有差异，常见项目包括：

- 服务地址
- API Key
- 模型
- 音色
- 语速

OpenAI、Gemini 和 MiniMax 会提供默认服务地址。使用第三方兼容服务时，可以选择 Custom HTTP 并填写服务端要求的参数。

配置完成后可以使用 **试听** 功能确认当前设置能否正常合成并播放声音。

## GPT-SoVITS

如果已经在本机或局域环境中运行 GPT-SoVITS HTTP 服务，可以选择 `GPT-SoVITS`。

默认服务地址为：

```text
http://127.0.0.1:9880
```

根据所使用的 GPT-SoVITS API，还可以填写参考音频、参考文本和语言等信息。

Nori 只负责调用已经可用的服务，不会自动训练或下载语音模型。

## 自动朗读与语速

开启自动朗读后，Nori 在生成回复时会把文字分段合成并依次播放。较长回复不需要等整段音频全部生成后才开始播放。

语音设置中还可以调节全局音量与语速。

## 实时口型同步

<UiChatPreview />

播放语音时，Nori 会根据实际播放音频的音量变化驱动 Live2D 嘴形。声音结束后嘴形会回到静止状态。

这个过程使用实际播放音频进行联动，因此不同 TTS 提供商都可以使用同一套口型同步逻辑。

## 麦克风语音输入

在对话页面使用麦克风按钮开始和结束录音。录音完成后，Nori 会把音频交给配置好的 Whisper 接口进行识别，再把识别结果作为文字返回到对话流程。

如果录音不可用，可以检查：

- 操作系统是否允许 Nori 使用麦克风
- Whisper 服务地址是否正确
- API Key 是否有效
- macOS 是否已经授予麦克风权限

## 隐私说明

录音数据通过 Nori 的本机媒体通道传递，不会直接塞进普通的界面消息中。是否需要把语音发送到远程服务器，取决于你配置的 TTS 或 Whisper 服务本身。
