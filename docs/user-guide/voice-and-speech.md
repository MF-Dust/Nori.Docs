# 开启语音

Nori 可以朗读回复，也可以把麦克风录音交给语音识别服务转换成文字。播放语音时，Live2D 角色会根据实际声音同步嘴形。

## 1. 选择朗读服务

进入 **设置 → 语音**：

<UiVoiceSettingsPreview />

当前语音合成可以使用：

- **OpenAI**
- **Gemini**
- **MiniMax**
- **IndexTTS-2**
- **GPT-SoVITS**
- **Custom HTTP**

使用官方云端服务时，按对应提供商填写信息即可；使用本地或自建服务时，再根据服务端说明填写地址和模型参数。

## 2. 填写语音设置

常见项目包括：

- 服务地址
- API Key
- 模型
- 音色
- 语速

不同提供商实际需要的字段会有差异，以设置页显示的内容为准。

## 3. 先试听一次

配置完成后使用 **试听**，确认音频能够正常生成和播放。

试听失败时，可以先检查服务地址、API Key、模型、网络，以及本地服务是否已经启动。

::: info 关于音频格式
当前原生播放管线使用 WAV。Custom HTTP 等自建服务需要返回可正常解码的 WAV 音频；仅修改 Content-Type 并不能把 MP3 或 OGG 变成 WAV。
:::

## 4. 开启自动朗读

开启自动朗读后，Nori 会把生成的回复交给当前 TTS 服务。较长回复可以分段生成和播放，不需要等整段文字全部结束后才开始说话。

## 用麦克风输入

语音识别使用 Whisper 接口。

在聊天界面使用麦克风入口开始和结束录音，Nori 会把录音交给已经配置好的 Whisper 服务，再把识别结果用于文字对话。

如果麦克风无法使用，可以检查：

- 操作系统是否允许 Nori 使用麦克风。
- Whisper 服务地址是否正确。
- API Key 是否有效。
- macOS 是否已经授予麦克风权限。

Nori 会根据真正送到系统声卡的声音计算音量变化，再驱动 Live2D 嘴形。它不依赖某一种 TTS 提供商，也不需要网页播放器参与。

## 使用 GPT-SoVITS

如果已经运行 GPT-SoVITS HTTP 服务，可以在语音设置中选择 **GPT-SoVITS**。

常见的本机地址为：

```text
http://127.0.0.1:9880
```

根据服务版本，还可以填写参考音频、参考文本和语言等信息。Nori 负责调用已经可用的服务，不会自动训练或下载语音模型。

## 隐私说明

文字或录音是否会发送到远程服务器，取决于你配置的 TTS 和 Whisper 服务。使用第三方服务前，可以查看对应服务商的隐私与数据处理说明。
