# 快速上手

这部分适合第一次使用 Nori，或者只想把软件正常用起来的用户。按照下面的顺序阅读，可以从下载安装到第一次和 Nori 对话，不需要了解源码或内部实现。

::: tip 建议的阅读顺序
下载与安装 → 和桌宠互动 → 连接 AI 模型 → 开启语音。其余功能都可以在之后按需要慢慢配置。
:::

## 1. 下载并启动 Nori

先前往 **[下载与安装](./environment-and-install.md)**，选择适合当前系统的发布包，安装必要的运行环境并完成首次启动。

当前稳定版为 **v1.3.0-Serika**，正式提供 Windows x64、Linux x64 和 macOS Apple Silicon 发布包。

## 2. 认识桌面上的 Nori

启动完成后，可以先试着拖动角色、调整大小、切换表情，再看看当前系统上的点击穿透效果。

这些操作都在 **[和桌宠互动](./desk-pet-interaction.md)** 中介绍。

## 3. 让 Nori 开始聊天

Nori 不会在安装包里附带大语言模型。要使用 AI 对话，需要连接一个你可以使用的模型服务，或者连接本机运行的兼容服务。

前往 **[连接 AI 模型](./ai-configuration.md)**，选择服务类型、填写连接信息并完成一次测试即可。

## 4. 开启语音

如果想让 Nori 朗读回复，或者用麦克风和她说话，可以继续阅读 **[开启语音](./voice-and-speech.md)**。

语音功能可以单独配置，不影响文字聊天。只想先打字使用时，也可以以后再设置。

🎉 到这里，Nori 最常用的桌宠、聊天和语音功能就已经可以使用了。

## 之后还可以做什么

- **[提醒与长期记忆](./memory-and-reminders.md)**：创建提醒，查看和管理长期记忆。
- **[技能与 MCP](./skills-and-mcp.md)**：为 Nori 接入更多工具和外部能力。
- **[插件](../guide/plugin-system.md)**：安装本地 `.noripack` 插件，扩展功能和界面。
- **[常见问题与排障](./troubleshooting-and-faq.md)**：启动失败、界面异常、AI 或语音无法连接时从这里查。

::: info 关于不同平台
Windows x64 是目前主要的完整验收平台。Linux 和 macOS 已有正式发布包，但托盘、全局鼠标和点击穿透等桌面能力会受到系统环境影响。需要时可以查看 [跨平台支持与能力差异](../operations/platform-matrix.md)。
:::
