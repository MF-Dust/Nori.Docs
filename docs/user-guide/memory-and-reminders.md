# 提醒与长期记忆

Nori 可以保存长期记忆，也可以管理定时提醒和主动互动。第一次使用时，只开启自己需要的部分就好。

## 创建提醒

最自然的方式是在聊天里直接说，例如：

- “20 分钟后提醒我喝水”
- “1 小时后提醒我交作业”
- “明天这个时间提醒我再检查一次”

当当前模型和工具允许时，Nori 会把这类请求创建成提醒。

也可以进入 **设置 → 主动互动** 手动添加提醒。设置页支持：

- 常用延迟时间
- 自定义分钟数
- 每天重复
- 查看和取消已有提醒

提醒会保存在本地，重启 Nori 后仍然存在。

## 主动互动

在 **设置 → 主动互动** 中，可以控制：

- **空闲互动**：一段时间没有操作后，允许 Nori 主动说话。
- **空闲分钟数**：决定等待多久。
- **每日问候**：在固定时段触发问候。

当前默认问候时段包括早晨、午餐和晚间。只有 Nori 正在运行时，这些主动行为才会触发。

## 长期记忆

<UiMemoryPreview />

记忆管理使用独立的原生窗口。你可以在里面查看 Nori 保存的记忆、提炼出的事实、知识文件和归档内容。

常用操作包括：

- 搜索和查看记忆
- 编辑错误内容
- 删除或归档不再需要的记忆
- 查看从记忆中提炼出的事实
- 管理 `Memory.md` 知识内容
- 调整记忆形成和检索相关设置

## 导入和导出

记忆窗口提供单独的传输页面。

导出后可以保存为文件或复制 JSON；导入时会先读取并预览，再由你选择冲突处理方式后真正写入。

这样可以在确认内容之前避免直接覆盖现有记忆。

## 安全模式

安全模式会暂停主动互动和新提醒，但仍可以查看已有提醒并进行必要的本地排障。

长期记忆窗口仍可用于查看和修改本地内容；需要联网或后台维护的部分会受到安全模式限制。

## 数据保存位置

记忆和提醒都属于 Nori 的本地数据，统一放在根目录下的 `data` 中。备份整个 `data` 文件夹时，它们会一起被保留。
