# 技能与 MCP

技能和 MCP 都能让 Nori 做得更多，但它们解决的问题不一样。

- **技能**更像一组行为说明，告诉 Nori 在某类任务里应该怎样做、优先使用哪些工具。
- **MCP**把外部工具真正接入 Nori，让模型可以调用文件、网页或其他服务提供的能力。

## 技能

进入 **设置 → 技能**：

<UiSkillsPreview />

技能页面可以查看当前技能，也可以启用、停用、从预设列表安装，或者按需要添加自定义技能。

当前预设覆盖生活、效率、游戏、语言和网络调研等方向。具体列表会随版本更新，因此文档不把所有技能名称写死。

技能本身不会自动获得无限权限。它能使用哪些工具，仍取决于当前工具配置和安全规则。

## MCP 是什么

MCP 是 Model Context Protocol。可以把它理解成 AI 和外部工具之间的一套通用接口。

Nori 当前支持两种连接方式：

- **stdio**：启动本机命令行 MCP 服务。
- **SSE**：连接 HTTP/HTTPS 上的 MCP 服务。

## 添加 MCP 服务

进入 **设置 → MCP**，添加服务器并填写对应信息。

### stdio

通常需要：

- 服务名称
- 启动命令
- 启动参数
- 可选环境变量

这类服务常见于 Node.js、Python 或其他本机工具。

### SSE

通常需要：

- 服务名称
- HTTP 或 HTTPS 地址

Nori 会按配置连接服务，并读取它公开的工具。

## 环境变量里有敏感信息怎么办

MCP 环境变量可能包含访问凭据。Nori 会把这类敏感配置按安全存储规则处理，不建议把凭据直接写进技能描述或聊天内容。

## 工具调用与审批

<UiMcpPreview />

AI 能看到哪些 MCP 工具，取决于当前连接状态和工具权限。

涉及修改外部状态或其他需要确认的操作时，Nori 会先显示审批内容；同意后才会继续，拒绝则取消当前调用。

## 服务连不上时

可以依次检查：

- stdio 命令能否在终端中正常启动
- 参数是否填写完整
- SSE 地址是否可以访问
- 环境变量是否缺失
- 当前是否处于安全模式

安全模式不会自动连接外部 MCP 服务。
