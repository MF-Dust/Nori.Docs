# 技能与定时提醒

技能会改变 Nori 处理某类任务时的行为方式；提醒则属于主动互动功能。两者都可以从原生设置窗口管理。

## 技能怎样工作

一个技能通常包含：

- 名称和说明
- 给 Nori 的行为指引
- 允许或推荐使用的工具
- 启用状态

技能可以是内置的，也可以来自预设列表或用户自定义内容。

## 预设技能

当前预设覆盖生活、效率、语言、游戏和网络调研等方向。

预设列表会跟着版本调整，所以文档不再固定写一张“永远不变”的技能表。打开 **设置 → 技能** 看到的列表才是当前版本的实际内容。

## 自定义技能

设置页可以新建自定义技能，也可以从网址安装受支持的技能内容。

自定义技能适合补充一组长期行为规则，例如：

- 遇到代码问题时优先检查可复现步骤。
- 做旅行规划时先确认时间和预算。
- 查询天气时主动调用天气工具。

技能说明里不适合放访问凭据或其他敏感信息。

## 创建提醒

进入 **设置 → 主动互动**，可以直接添加提醒。

当前支持：

- 5、15、30、60 分钟等常用延迟
- 自定义分钟数
- 每天重复
- 查看和取消已有提醒

也可以在聊天中用自然语言创建提醒，只要当前 Agent 拥有相应工具。

## 空闲互动与每日问候

主动互动设置还可以控制：

- 空闲一段时间后是否允许 Nori 主动说话
- 空闲等待分钟数
- 每日固定时段问候

这些功能只在 Nori 正在运行时生效。

## 安全模式

`--safe-mode` 会暂停主动互动和创建新提醒，但已有提醒仍可以查看和取消。

技能和外部工具的可用范围也会受到安全模式限制。
