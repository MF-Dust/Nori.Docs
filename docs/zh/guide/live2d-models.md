# Live2D 桌宠与模型管理

Nori 的桌面角色使用本机 Live2D 渲染，不依赖网页里的 Canvas 来显示桌宠。对普通用户来说，更重要的是模型如何导入、切换、调整和互动。

## 当前桌宠支持的体验

当前桌宠可以提供：

- Live2D 动作与表情
- 自动眨眼与物理效果
- 鼠标视线跟随
- 语音播放时的口型联动
- 桌宠拖动与位置保存
- 支持平台上的透明区域点击穿透
- 模型互动区域与动作反馈

不同模型自带的动作、表情和参数数量可能不同，因此文档不会把某一套模型的具体动作当成所有模型都具备的固定功能。

## 点击穿透与拖动

Nori 会根据桌宠当前可见区域更新窗口的可交互范围，让模型周围的空白区域尽量不挡住桌面操作。

Windows 当前主分支已经恢复点击穿透；Linux X11、Wayland 与 macOS 的具体表现见 [跨平台支持与能力差异](../operations/platform-matrix.md)。

拖动时会设置一个很小的移动阈值，避免普通点击被误判成拖拽。松开鼠标后，位置会自动保存。

## 本地模型保存位置

正式版模型位于 Nori 数据目录中：

```text
<PackageRoot>/data/resources/installed/live2d/<model-id>/
```

当前产品识别的本地模型包括：

- `arg-nori`
- `nori`

Nori 不提供远程模型下载器、模型 CDN 或在线模型市场。模型需要已经存在于本地资源库，或者由用户从本地文件导入。

## 导入 Live2D 模型

在主控制台的 **模型** 页面选择 **导入本地模型**，可以导入 ZIP 或本地目录。

Nori 会先检查文件路径和模型结构，再把通过检查的资源加入本地模型库。这样比直接手动复制文件到数据目录更稳妥。

通常模型需要包含有效的 `*.model3.json`、对应的 `.moc3`、纹理以及模型实际引用的其他资源。

为了避免恶意或损坏压缩包影响本机文件，导入流程会拒绝明显越界的路径、绝对路径、符号链接等危险内容。

## 调整模型

<UiModelPreview />

当前模型调整界面主要提供：

- **缩放**：50% 到 200%
- **表情**：读取当前模型实际提供的表情列表，并选择一个表情或清除选择

旧文档曾写有透明度、渲染倍率、帧率上限和画质档位等控件，这些并不属于当前调整面板，已经从文档中移除。

## 互动区域

模型管理中还包含互动区域相关设置，可以为模型定义可点击区域，并把区域与模型动作或表情联系起来。

具体区域名称和效果由当前模型配置决定。某个模型可以有头部、脸部或身体等区域，另一个模型也可以使用完全不同的区域，因此没有统一固定表。

## 设置页预览和桌面角色的区别

设置页面中的模型预览用于调整和检查模型；真正显示在桌面上的角色由桌宠窗口负责。

如果预览正常但桌宠行为异常，可以结合平台兼容性、点击穿透设置和诊断日志继续排查。

## 备份模型

自定义模型位于 Nori 根目录下的 `data` 数据区域。备份整个 `data` 文件夹时，已导入的本地模型也会一起保留。
