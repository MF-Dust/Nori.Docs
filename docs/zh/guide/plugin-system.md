# 安装与使用插件

Nori 可以通过 `.noripack` 安装本地插件。插件能够增加新的操作、独立小窗口，也可以在聊天区域显示自己的交互内容。

::: warning 只安装可信来源的插件
插件属于本机扩展，能做的事情比普通网页更多。安装前请确认来源可信，或者使用自己检查、编译的插件包。
:::

## 安装插件

打开 **设置 → 插件**，选择本地 `.noripack` 文件：

<UiPluginsPreview />

安装完成后，新插件默认保持关闭状态。确认插件来源和用途后，再手动启用即可。

当前没有在线插件市场，也不会自动替你下载或更新第三方插件。

## 启用和禁用

插件可以在设置页面随时启用或禁用。

多数插件可以直接切换状态；如果某个插件无法在运行中安全退出，Nori 会提示在重启后完成切换。

## 插件可以增加什么

当前 NPS 2.0 主要支持：

- **插件动作**：为 Nori 增加新的可调用操作，启用后也可以交给 AI 在对话中使用。
- **插件窗口**：提供插件自己的独立界面。
- **聊天卡片**：把播放控制、状态面板、搜索结果等交互内容直接显示在聊天区域。

不同插件提供的功能并不相同，实际内容以插件自己的说明为准。

## 插件导致 Nori 无法正常启动

可以使用安全模式启动 Nori：

```text
--safe-mode
```

安全模式不会加载第三方插件，但仍然可以打开插件列表。这样可以直接禁用或卸载刚安装的故障插件。

详情见 [安全模式](../operations/safe-mode.md)。

## 卸载与插件数据

卸载插件时，可以按界面选项决定是否同时删除该插件保存的数据。

如果只是暂时排查问题，可以先禁用插件；确认不再需要时再卸载。

## 插件开发

想为 Nori 制作插件时，可以使用公开的 **`Nori.PluginSDK` 2.0.0**，目标框架为 .NET 10：

```bash
dotnet add package Nori.PluginSDK --version 2.0.0
```

SDK 仓库和示例位于 [MF-Dust/Nori.PluginSDK](https://github.com/MF-Dust/Nori.PluginSDK)。

::: details 聊天卡片约定
插件包可以提供 `web/card.html` 作为聊天卡片入口。卡片通过 Nori 开放的通信能力请求插件动作，主程序不需要为某个具体插件写专属卡片。
:::

::: info 当前插件边界
NPS 2.0 已提供插件动作、插件窗口和聊天卡片等能力，但当前没有 Marketplace、统一签名商店或自动更新服务。
:::
