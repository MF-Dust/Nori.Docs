# AI 对话与 Agent

这页补充 Nori 的 AI 对话配置和工具调用方式。第一次连接模型时，先看 [连接 AI 模型](../user-guide/ai-configuration.md) 会更直接。

## 支持哪些接口

当前设置中可以选择：

| 类型 | 适合的情况 |
| :--- | :--- |
| **OpenAI** | OpenAI Chat Completions，以及兼容这一接口的第三方或本地服务 |
| **OpenAI Responses** | 使用 Responses API 的服务 |
| **Anthropic** | Anthropic 官方接口 |
| **Google** | Google Gemini 接口 |

如果服务商明确写着“OpenAI 兼容”，通常选择 OpenAI 类型即可。

## 拉取模型和测试连接

填写服务地址与访问凭据后，可以先获取模型列表，再使用连接测试确认当前配置是否可用。

连接测试不会把你的聊天历史或长期记忆当作测试内容写入数据库。

## 凭据怎么保存

敏感配置使用当前的 `nsec2:` 加密格式保存。系统会优先把主密钥交给 Windows DPAPI、macOS Keychain 或 Linux libsecret 保护。

设置界面不会为了刷新状态重新显示已经保存的完整凭据。

更多信息见 [凭据与本地数据安全](../reference/security-spec.md)。

## 对话时会带上什么

一次正常对话通常会根据当前设置组合这些内容：

- Nori 的基础人设与自定义人设
- 最近对话
- 检索到的长期记忆
- 当前启用的技能
- 可以使用的工具

对话变长后，Nori 会控制上下文大小，优先保留当前任务更需要的信息，避免无限堆积历史消息。

## 工具、技能和插件怎样参与对话

- **技能**主要补充行为说明，并限制或推荐当前适合使用的工具。
- **MCP**可以把外部服务提供的工具接入 Nori。
- **插件**可以注册受信任的本机动作。
- **内置工具**提供提醒、桌面状态、Live2D 互动等能力。

需要用户确认的操作会在执行前交给界面审批。工具是否可用，还会受到平台能力、安全模式和当前设置影响。

## 表情与动作

Nori 的 Agent 可以把支持的情绪、表情或动作意图交给 Live2D 伴侣视窗。具体能播放什么，取决于当前模型本身提供的动作和表情。

因此不同 Live2D 模型的表现可能不一样，这属于正常情况。
