# 界面与窗口行为

Nori 2.x 的用户界面已经迁移到 Avalonia 原生窗口。聊天、设置、记忆和模型管理都由桌面宿主直接显示，不再依赖旧版 WebView 界面。

## 你会看到哪些窗口

启动和日常使用中，常见窗口包括：

- **首次运行向导**：第一次使用时出现，用来完成基础设置。
- **初始化界面**：启动过程中短暂显示。
- **主窗口**：日常对话和主要入口。
- **伴侣视窗**：单独显示 Live2D 角色。
- **设置、记忆与模型窗口**：需要时单独打开，并各自保存当前操作状态。

插件目前不会向 Nori 注入自定义页面或聊天卡片。

## 关掉主窗口后为什么 Nori 还在

在支持托盘的平台上，关闭主窗口通常只是把它隐藏，桌面伴侣和后台功能可以继续运行。

想完全退出 Nori 时，可以使用托盘或应用提供的退出入口。

## 语音还依赖主窗口吗

不依赖。

2.x 的播放和录音都由桌面宿主直接访问系统音频设备。隐藏主窗口不会让正在使用的原生音频后端变回网页播放，也不需要保持 WebView 页面运行。

## 伴侣视窗为什么单独存在

Live2D 角色需要透明背景、置顶、拖动、鼠标跟随和点击穿透等桌面窗口能力。把它和普通功能界面分开，可以让角色保持轻量，也能按不同平台的能力自动降级。

## 点击穿透为什么不同平台不一样

Windows、X11、Wayland 和 macOS 对透明窗口输入区域的支持不同。

- Windows 支持模型区域与透明区域的点击穿透处理。
- Linux X11 可以使用窗口输入区域。
- Wayland 缺少同等的全局能力，可能退化为整窗可点击和窗口内鼠标跟随。
- macOS 使用系统提供的鼠标忽略能力。

详情见 [跨平台支持与能力差异](../operations/platform-matrix.md)。

## 系统托盘

在支持托盘的平台上，可以从托盘快速打开主窗口、显示或隐藏 Nori，以及退出程序。

Linux 的托盘支持取决于桌面环境。托盘不可用时，Nori 仍会保留其他可操作入口。
