# 常见问题排查与安全模式

本章节汇总了日常使用中可能遇到的常见疑问、自查排障步骤以及安全模式的使用方法。

---

## 1. 启动与界面常见问题

### 问题一：双击 `Nori.Desktop.exe` 后没有任何反应或直接闪退？
- **可能原因**：电脑中缺少必需的 .NET 10 桌面运行库或 WebView2 运行时。
- **解决办法**：
  1. 重新前往官网下载并安装 [.NET 10.0 Desktop Runtime (x64)](https://dotnet.microsoft.com/download/dotnet/10.0)。
  2. 确认已安装 [Microsoft Edge WebView2 独立运行时](https://developer.microsoft.com/microsoft-edge/webview2/)。

### 问题二：启动后一直停留在转圈加载界面？
- **可能原因**：之前填写的某些外部接口发生网络死锁或配置文件损坏。
- **解决办法**：使用下文介绍的 **安全模式** 启动，重置或修复异常的设置项。

### 问题三：桌宠突然不见了怎么找回？
- **可能原因**：被误设为隐藏，或者被拖到了屏幕可视范围之外。
- **解决办法**：
  1. 鼠标右键点击电脑任务栏右下角的 Nori 小图标，选择 **「显示/隐藏桌宠」**。
  2. 双击托盘图标打开主控制台，在「主页」顶部重新开启桌宠开关。

## 2. AI 对话与语音问题

### 问题四：发送消息后提示网络错误或长时间无响应？
- **可能原因**：API Key 填写错误、账号余额不足或 Base URL 地址填错。
- **解决办法**：
  1. 进入 **「设置」→「AI 设置」**。
  2. 点击对应服务商旁边的 **「测试连接」** 按钮，查看具体返回的报错信息（如认证失败 401、地址不存在 404 等）。
  3. 若使用本地 Ollama，在电脑命令行中输入 `ollama list` 确认本地大模型服务已正常启动。

### 问题五：收到文字回复但听不到声音？
- **可能原因**：主音量为 0、未开启自动朗读或 TTS 密钥未填写。
- **解决办法**：
  1. 进入 **「设置」→「语音」**，检查主音量滑块与「自动朗读回复」开关是否开启。
  2. 点击「测试发音」按钮确认发音引擎是否工作正常。

## 3. 安全排障模式 (`--safe-mode`)

<UiDebugPreview />

当配置错误导致常规启动崩溃时，可以使用专门的 **安全排障模式** 快速修复：

### 如何启动安全模式
在终端、命令提示符或 PowerShell 中执行：
```powershell
.\Nori.Desktop.exe --safe-mode
```

### 安全模式的特点
- **隔离重型外部服务**：暂时跳过联网聊天、跳过外部 MCP 自动连接与 Live2D 自动加载，杜绝启动阻塞。
- **保留完整设置面板**：允许你从容地在控制台中修改错误的 API 密钥、删除故障插件或纠正配置。
- **修复完成后**：关闭程序，正常双击 `Nori.Desktop.exe`（不带参数）即可恢复全部正常功能。

## 4. 导出脱敏诊断包与反馈 Bug

如遇到无法自行解决的问题，可生成安全的脱敏诊断包提交至官方社区：

1. 打开主控制台，进入 **「设置」→「调试」**。
2. 点击 **「导出诊断信息」** 按钮。
3. 系统会在后台生成一份 ZIP 压缩包（仅包含版本信息与脱敏运行日志，**绝对不包含你的聊天记录、隐私记忆或任何密码密钥**）。
4. 前往 [GitHub 官方 Issue 页面](https://github.com/MF-Dust/Nori-Desktop-Pet/issues) 提交工单并附上该诊断文件。
