# 用户操作手册总览

这份手册面向日常使用 Nori 的用户。下载安装、桌宠互动、AI、语音、提醒、长期记忆、MCP 与排障都可以从这里找到，不需要了解项目内部代码。

## 当前版本

截至 2026 年 8 月 30 日，最新稳定版为 **v1.3.0-Serika**。

目前正式 Release 提供：

- Windows x64
- Linux x64
- macOS Apple Silicon

Windows x64 仍是项目最主要的实际验收平台。Linux 和 macOS 已有正式发布包，但不同桌面环境下的窗口、托盘和点击穿透能力会有差异。

## Nori 现在可以做什么

- **桌面陪伴与互动**：Live2D 桌宠支持拖动、视线跟随、触摸反馈与透明区域点击穿透。
- **AI 对话**：可以连接多种云端模型服务，也可以连接本地 Ollama 等 OpenAI 兼容服务。
- **语音交流**：支持 TTS 朗读、麦克风语音输入和实时口型联动。
- **提醒与长期记忆**：可以创建提醒，并查看、修改或删除本地保存的长期记忆。
- **MCP 工具**：可以为 Nori 接入外部工具，并对需要确认的操作进行人工审批。
- **本地插件**：支持 `.noripack` 插件。插件可以增加工具、独立界面，也可以在聊天区域显示自己的交互卡片。
- **安全排障**：提供 `--safe-mode` 安全模式和脱敏诊断导出。

::: tip 关于本地模型
Nori 当前只管理本地 Live2D 资源，不提供在线模型市场或自动下载模型的服务。自定义模型需要从本地 ZIP 或目录导入。
:::
