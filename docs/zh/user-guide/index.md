# 快速上手

这部分写给第一次使用 Nori 的用户。按下面的顺序走一遍，就能从下载一直到第一次聊天和语音互动，不需要先了解项目内部结构。

::: tip 推荐顺序
下载与安装 → 桌面伴侣互动 → 连接 AI 模型 → 开启语音。记忆、提醒、技能和插件都可以之后再慢慢配置。
:::

## 1. 下载并启动 Nori

先查看 **[下载与安装](./environment-and-install.md)**，选择适合当前系统的发布包，安装需要的 .NET 运行环境并完成首次启动。

当前稳定版为 **v2.0.2-Kei**，正式提供 Windows x64、Linux x64 和 macOS Apple Silicon 发布包。

## 2. 认识桌面上的 Nori

启动完成后，可以先试着拖动角色、调整大小、切换表情，再看看当前系统上的点击穿透效果。

这些操作都在 **[桌面伴侣互动](./desk-pet-interaction.md)** 中介绍。

## 3. 让 Nori 开始聊天

Nori 的安装包不会附带大语言模型。要使用 AI 对话，需要连接一个你可以使用的模型服务，也可以连接本机运行的兼容服务。

前往 **[连接 AI 模型](./ai-configuration.md)**，选择服务类型、填写连接信息并完成一次测试即可。

## 4. 开启语音

如果想让 Nori 朗读回复，或者使用麦克风输入，可以继续阅读 **[开启语音](./voice-and-speech.md)**。

语音可以单独配置，不影响文字聊天。只想先打字使用时，也可以以后再设置。

## 之后还可以做什么

- **[提醒与长期记忆](./memory-and-reminders.md)**：创建提醒，查看、修改、导入和导出长期记忆。
- **[技能与 MCP](./skills-and-mcp.md)**：为 Nori 接入更多提示能力和外部工具。
- **[插件](../guide/plugin-system.md)**：安装本地 `.noripack` 插件，为 AI 增加受信任的本机动作。
- **[常见问题与排障](./troubleshooting-and-faq.md)**：启动失败、界面异常、AI 或语音无法连接时从这里查。

::: info 关于不同平台
Windows x64 是当前主要验收平台。Linux 和 macOS 已有正式发布包，但托盘、全局鼠标和点击穿透等桌面能力会受到系统环境影响。详情见 [跨平台支持与能力差异](../operations/platform-matrix.md)。
:::
