# 用户操作手册总览

欢迎使用 Nori Desktop Pet（Nori桌面智能伴侣）。本手册面向普通用户编写，无需任何编程基础，涵盖从环境准备、软件安装、桌面互动、AI 大模型对接、语音配置、生活提醒一直到 MCP 扩展集成的完整操作指引。

---

## 1. 软件概述与核心能力

Nori 是一款常驻于 Windows 桌面的二次元 Live2D 智能伴侣程序，具备以下核心能力：

- **桌面陪伴与互动**：基于 Live2D 动态模型，视线跟随鼠标移动，支持摸头、戳脸、拍打等肢体动作与表情反馈；支持智能透明穿透，不阻碍正常的日常办公与游戏。
- **智能对话交流**：支持连接国内外主流大语言模型（如 DeepSeek、通义千问、OpenAI、Claude、Gemini 以及本地离线运行的 Ollama），提供自然流畅的打字机对话体验。
- **拟真发音与口型同步**：支持文字转语音（TTS）自动朗读，并根据说话音量实时驱动桌宠张嘴开合；支持麦克风语音输入。
- **生活备忘与定时提醒**：在对话中通过自然语言一句话设置倒计时提醒（如“半小时后提醒我喝水”），到时准时提醒。
- **长期记忆与喜好沉淀**：自动从日常交流中提取用户的姓名、偏好、习惯与日程，建立个人专属记忆库，支持随时查阅与修改。
- **MCP 外部工具扩展**：支持接入标准 Model Context Protocol（MCP）生态，让伴侣具备操作本地文件、网页搜索等扩展技能，且所有高危操作均支持人工确认审批。
