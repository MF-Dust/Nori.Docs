# 技能与 MCP 工具集成实战

Nori 支持安装专项技能包并无缝接入开放标准 **Model Context Protocol（MCP）**，让你的桌面伴侣不仅能陪你聊天，更能具备读取本地文件、搜索网页、管理 GitHub 等强大的外部工具操作能力。

---

## 1. 技能系统（Skills System）

技能允许一键为 Nori 注入特定领域的系统提示词（Prompt）与行为准则：

### 启用预设技能
打开主控制台，进入 **「设置」→「技能」**：
- **编程助理 (Coding)**：强化代码逻辑审查、Bug 分析与重构建议。
- **任务管理 (Productivity)**：专注日程规划与结构化待办整理。
- **游戏玩伴 (Gaming)**：活泼生动的联机玩伴模式，分享游戏趣事与互动。

---

## 2. 什么是 MCP？（Model Context Protocol）

MCP 是由 Anthropic 主导并被行业广泛支持的开放通信协议：
- **通俗理解**：MCP 就像是给 AI 大模型装上的“外设接口”，让 Nori 能够安全地调用你电脑上的第三方工具插件（例如读取本地指定文件夹里的文档、抓取网页内容或执行查询）。
- **运行模式**：主要通过 `stdio` 管道拉起本地命令行服务（如 Node.js / Python 工具包）。

---

## 3. 前置运行环境准备

使用大部分开源 MCP 服务前，建议确保电脑已安装以下常用运行环境：
1. **Node.js (推荐)**：前往 [Node.js 官方网站](https://nodejs.org/) 下载安装 LTS 版本（自带 `npx` 命令行工具）。
2. **Python / uv (可选)**：如果使用 Python 编写的 MCP 工具，可安装 Python 3.10+ 或 [uv](https://docs.astral.sh/uv/)。

## 4. 实战教程：配置常用 MCP 工具服务器

打开主控制台，点击 **「设置」→「MCP」**，点击 **「添加服务器」**：

```text
┌────────────────────────────────────────────────────────┐
│ 添加 MCP 服务器                                        │
├────────────────────────────────────────────────────────┤
│ 服务标识 (ID): mcp_filesystem                          │
│ 服务名称:      本地文件系统工具                        │
│ 传输协议:      [ Stdio ]                               │
│ 执行命令:      npx                                     │
│ 启动参数:      -y @modelcontextprotocol/server-filesystem
│                C:\Users\SakuraStar\Documents           │
│ 环境变量:      KEY=VALUE (可选)                        │
│ 状态开关:      [x] 启用服务   [x] 启动时自动连接       │
└────────────────────────────────────────────────────────┘
```

### 常用 MCP 配置模版

#### 示例一：本地文件读取与管理（Filesystem）
- **服务名称**：本地文件操作
- **传输协议**：`stdio`
- **执行命令**：`npx`
- **参数列表**：`["-y", "@modelcontextprotocol/server-filesystem", "你的工作文件夹路径"]`
- **生效效果**：在对话中允许 Nori 读取或分析你指定目录下的文档与代码。

#### 示例二：网页内容抓取与网页搜索（Fetch）
- **服务名称**：网页抓取工具
- **传输协议**：`stdio`
- **执行命令**：`uvx`（或 `npx`）
- **参数列表**：`["mcp-server-fetch"]`
- **生效效果**：在对话中给 Nori 一个网址，她能够直接抓取网页正文并为你总结提炼。

#### 示例三：GitHub 仓库与 Issue 管理
- **服务名称**：GitHub 助理
- **传输协议**：`stdio`
- **执行命令**：`npx`
- **参数列表**：`["-y", "@modelcontextprotocol/server-github"]`
- **环境变量**：`{"GITHUB_PERSONAL_ACCESS_TOKEN": "你的GitHub个人令牌"}`

## 5. 工具调试与人工在环二次审批（安全机制）

<UiMcpPreview />

### 工具列表与手动调试
- 在「MCP 设置」面板中切换至 **「内置与工具」** 标签，可查看当前所有已连接服务提供的工具函数清单。
- 点击工具右侧的「手动测试」按钮，可以在不消耗聊天 Token 的情况下直接输入参数验证执行结果。

### 高危操作人工二次审批卡片
为了防止大模型产生“幻觉”误删文件或执行非预期操作：
1. 当 Nori 试图调用具有修改或敏感权限的工具时，系统会自动拦截并挂起执行；
2. 聊天视口中会弹出清晰的 **审批卡片（Approval Card）**，展示即将调用的工具名称、目标文件路径与参数内容；
3. 只有在你亲自点击 **「允许执行」** 后，外部操作才会真正生效；若点击 **「拒绝」**，Nori 会立刻取消调用并继续对话。
