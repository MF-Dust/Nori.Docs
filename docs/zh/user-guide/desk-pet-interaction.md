# 桌宠交互与外观调节

这一页介绍当前版本里用户实际能操作的桌宠功能，包括移动、点击穿透、模型切换、缩放、表情和本地模型导入。

## 移动桌宠

把鼠标放到桌宠模型区域，按住左键并拖动即可移动 Nori。

为了避免普通点击被误判成拖动，程序会在鼠标移动超过一个很小的距离后才开始拖拽。松开鼠标后，位置会被保存，后续启动时继续使用。

## 点击穿透

在支持的平台上，Nori 可以让模型周围的空白区域把鼠标事件交给后面的桌面窗口，这样桌宠不会占住整块透明窗口。

点击穿透可以在 **设置 → 通用** 中开关。如果当前系统不支持，界面会把这个选项标记为不可用。

不同平台的表现有差异：

- Windows：当前主分支已恢复点击穿透功能。
- Linux X11：可以使用窗口输入区域实现穿透。
- Linux Wayland：受系统协议限制，可能退化为整窗可点击。
- macOS：使用系统对应的鼠标忽略机制。

详情见 [跨平台支持与能力差异](../operations/platform-matrix.md)。

## 触摸与互动

Nori 支持模型互动区域。具体可以点击哪些部位、触发什么动作或表情，取决于当前 Live2D 模型及其互动配置。

因此文档不把“摸头一定触发某个固定表情”写成所有模型都具备的统一行为。

## 隐藏和重新显示桌宠

Windows 和 macOS 通常可以通过系统托盘控制桌宠显示状态。

Linux 是否有托盘入口取决于桌面环境。如果托盘不可用，主控制台仍会保留桌宠显示相关操作。

## 调整模型大小和表情

打开模型管理页面，进入当前模型的调整区域：

<UiModelPreview />

当前调整面板提供：

- **模型缩放**：范围为 50% 到 200%。
- **表情选择**：如果模型提供表情列表，可以选择一个表情预览或清除当前选择。

旧文档曾写到透明度、渲染倍率、帧率上限和底部阴影等调节项，这些并不属于当前 `AdjustControls` 的实际界面，因此已经移除。

## 切换内置模型

当前产品识别的本地模型包括：

- `arg-nori`
- `nori`

模型需要已经存在于本地资源库中才能启用。Nori 不会从远程 CDN 自动下载这些模型。

## 导入自己的 Live2D 模型

模型管理页支持从本地 ZIP 或目录导入 Live2D 资源。

建议使用界面提供的导入功能，由 Nori 完成解压、路径检查和模型结构验证，不要直接把未知文件手动塞进程序数据目录。

通常需要有效的 `*.model3.json`、对应的 `.moc3` 文件以及模型引用的纹理等资源。最终能否正常加载仍取决于模型文件本身是否完整、格式是否受当前 Cubism 运行时支持。

## 模型文件保存位置

正式版的本地模型会存放在 Nori 根目录下的 `data` 数据区域中。备份整个 `data` 文件夹时，自定义模型也会一起被保留。
