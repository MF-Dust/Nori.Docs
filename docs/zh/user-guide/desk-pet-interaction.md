# 和桌宠互动

这一页介绍桌面上最常用的操作。启动 Nori 后，可以直接跟着页面试一遍。

## 移动 Nori

把鼠标放到角色上，按住左键拖动，就可以把 Nori 移到桌面的其他位置。松开后，当前位置会自动保存。

## 让点击穿过透明区域

桌宠窗口本身是透明的。开启点击穿透后，模型周围的空白区域不会挡住后面的桌面和应用。

在 **设置 → 通用** 中可以找到点击穿透开关。当前系统不支持时，这个选项会显示为不可用。

::: tip Linux 用户
X11 下可以使用窗口输入区域实现穿透。Wayland 受到系统协议限制，部分桌面环境中可能只能让整个窗口保持可点击。需要更详细的信息可以查看 [跨平台支持与能力差异](../operations/platform-matrix.md)。
:::

## 点击和触摸互动区域

有些 Live2D 模型会为头部、身体或其他位置设置互动区域。点击这些区域时，可以触发模型自己的动作或表情。

每个模型的配置可能不同，所以实际能互动的位置和效果以当前模型为准。

## 调整大小和表情

打开模型管理，进入当前模型的调整区域：

<UiModelPreview />

这里可以：

- 把模型缩放到 **50%–200%**。
- 从模型提供的表情中选择一个进行预览，也可以清除当前表情。

## 切换模型

已经安装到本地的模型会显示在模型管理中。选择想使用的模型并启用后，桌面角色会切换到对应模型。

Nori 当前不会自动从远程模型市场下载 Live2D 资源。

## 导入自己的 Live2D 模型

模型管理支持从本地 ZIP 或目录导入 Live2D 模型。

优先使用界面里的导入功能即可。Nori 会处理解压和基础检查，比手动修改数据目录更稳妥。

::: details 模型文件需要包含什么？
通常需要有效的 `*.model3.json`、对应的 `.moc3` 文件，以及模型引用的纹理等资源。最终能否加载还取决于模型文件是否完整、格式是否受当前 Cubism 运行时支持。
:::

## 备份模型和设置

本地模型和相关设置都保存在 Nori 的 `data` 数据目录中。备份整个 `data` 文件夹时，自定义模型也会一起保留。
