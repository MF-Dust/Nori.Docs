# 开启语音

Nori 可以把回复读出来，也可以把麦克风录音转换成文字。语音播放时，Live2D 角色会跟随实际声音同步嘴形。

## 1. 选择朗读服务

进入 **设置 → 语音**：

<UiVoiceSettingsPreview />

当前 TTS 可以选择：

- **OpenAI**
- **Gemini**
- **MiniMax**
- **Custom HTTP**
- **GPT-SoVITS**

如果使用官方云端服务，选择对应提供商即可；如果使用自己部署的兼容接口，可以根据服务情况选择 Custom HTTP 或 GPT-SoVITS。

## 2. 填写语音设置

不同服务需要的内容会略有差异，常见项目包括：

- 服务地址
- API Key
- 模型
- 音色
- 语速

OpenAI、Gemini 和 MiniMax 会提供默认服务地址。使用第三方或本地服务时，再按服务端说明修改地址和参数。

## 3. 先试听一次

配置完成后使用 **试听**，确认声音可以正常生成和播放。

如果试听失败，可以先检查服务地址、API Key、模型和当前网络。使用本地服务时，也要确认服务已经启动。

## 4. 开启自动朗读

开启自动朗读后，Nori 会在生成回复时分段合成并依次播放，因此较长回复不需要等整段音频全部生成后才开始说话。

还可以在语音设置中调整全局音量和语速。

## 用麦克风输入

语音识别使用 **Whisper 接口**。

在聊天页面点击麦克风按钮开始录音，再次操作结束录音。Nori 会把录音交给已经配置好的 Whisper 服务进行识别，并把结果带回文字对话。

如果麦克风无法使用，可以检查：

- 操作系统是否允许 Nori 使用麦克风。
- Whisper 服务地址是否正确。
- API Key 是否有效。
- macOS 是否已经授予麦克风权限。

## 口型同步

<UiChatPreview />

只要语音正在播放，Nori 就会根据实际播放音量驱动 Live2D 嘴形。播放结束后，嘴形会回到静止状态。

这套联动使用的是最终播放出来的声音，所以不局限于某一种 TTS 提供商。

## 使用 GPT-SoVITS

如果已经运行 GPT-SoVITS HTTP 服务，可以在语音设置中选择 **GPT-SoVITS**。

常见的本机默认地址为：

```text
http://127.0.0.1:9880
```

根据所使用的 API，还可以填写参考音频、参考文本和语言等信息。Nori 负责调用已经可用的服务，不会自动训练或下载语音模型。

::: info 旧版语音配置
浏览器 Web Speech 与 Edge TTS 路径已经停用。检测到旧配置时，Nori 会提示迁移到当前支持的语音提供商。
:::

## 隐私说明

是否会把文字或录音发送到远程服务器，取决于你配置的 TTS 和 Whisper 服务。使用第三方服务前，可以先查看对应服务商的隐私与数据处理说明。

🎉 到这里，最常用的桌宠、文字聊天和语音功能都已经配置好了。
