# 生活提醒与长期记忆

Nori 不仅是一位倾听者，更能担当贴心的日常生活管家。本章节介绍如何使用自然语言定时提醒功能，以及如何查看和管理 Nori 对你的长期记忆。

---

## 1. 怎么让 Nori 提醒你？（定时待办与生活备忘）

### 方式一：自然语言快速创建（推荐）
在与 Nori 的日常聊天中，直接发送带有时间意图的指令即可：
- *“20 分钟后提醒我喝水”*
- *“下午 3 点 30 分提醒我参加部门会议”*
- *“45 分钟后提醒我站起来活动一下颈椎”*

Nori 的智能 Agent 引擎会自动识别时间与事项，并在后台创建定时提醒任务。

### 方式二：在控制台中手动创建与管理
进入 **「设置」→「主动行为」**：
1. 点击「添加提醒」按钮；
2. 输入提醒事项内容与延迟触发分钟数；
3. 点击保存后即可在下方的提醒列表中看到待触发项。

### 提醒到期时的交互方式
当设定时间到达时：
- 桌面上的桌宠会做出引起注意的动作并发出提示；
- 屏幕上会弹出提醒卡片，你可以选择：
  - **推迟 (Snooze)**：延长 5 分钟、10 分钟或 15 分钟后再次提醒；
  - **完成 (Complete)**：标记该事项已完成，提醒结束。

## 2. 空闲关怀与每日问候（Proactive Scheduler）

<UiSkillsPreview />

在 **「设置」→「主动行为」** 中可以开启贴心的主动陪伴功能：
- **空闲智能关怀**：可设定空闲分钟数（如 15 分钟）。当检测到你长时间未操作键盘鼠标时，Nori 会主动轻声询问是否在休息，提醒你不要太劳累。
- **每日清晨问候**：每天第一次开机或回到电脑前时，Nori 会向你致以温暖的早间问候。

## 3. 查看与管理 Nori 的长期记忆（Living Memory）

<UiMemoryPreview />

在日常交流中，Nori 会自动提取关于你的偏好、习惯与重要事实（如你喜欢的食物、常玩的编程语言、宠物名字等）。

打开主控制台，点击左侧导航的 **「记忆 (Memory)」**：

```text
┌────────────────────────────────────────────────────────┐
│ 记忆库概览 (Living Memory)                             │
├────────────────────────────────────────────────────────┤
│ 活跃记忆: 15 条  │  记忆原子: 32 个                    │
├────────────────────────────────────────────────────────┤
│ 搜索过滤: [ 关键词搜索...          ] [ 全部类型 ▼ ]    │
│                                                        │
│ • [用户偏好] 喜欢在写代码时喝乌龙茶与无糖可乐          │
│ • [客观事实] 拥有一只叫波波的布偶猫                    │
│ • [生活计划] 计划在周末整理书架并去图书馆              │
│                                                        │
│ 操作操作: [ 编辑内容 ] [ 导出为 JSON ] [ 彻底删除 ]    │
└────────────────────────────────────────────────────────┘
```

### 记忆库核心操作
1. **查阅记忆**：在记忆列表中清晰查看 Nori 对你的全部认知印象。
2. **修改纠错**：如果 Nori 记录的内容存在偏差，点击右侧的「编辑」按钮可直接手动修改内容与标签。
3. **彻底删除**：若不希望 Nori 保留某条隐私信息，点击「删除」即可从本地数据库中彻底抹除。
4. **备份与迁移**：点击「导出记忆」可将全部记忆保存为 JSON 格式文件，在更换电脑或重装系统时可一键导入还原。
