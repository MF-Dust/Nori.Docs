# 长期记忆与知识库

这页介绍长期记忆的进阶使用。只想查看、修改或备份记忆时，先看 [提醒与长期记忆](../user-guide/memory-and-reminders.md) 会更直接。

## 记忆窗口里有什么

Nori 2.x 使用独立的原生记忆窗口。当前可以查看这些分区：

- **概览**：查看记忆库整体状态。
- **记忆**：浏览长期记忆条目。
- **记忆原子**：查看从记忆中提炼出的事实和来源。
- **知识**：管理 `Memory.md` 与检索索引。
- **归档**：放置暂时不参与日常检索的记忆。
- **传输**：导入、导出和处理冲突。
- **调试**：检查一次检索最终用了哪些记忆。
- **高级设置**：调整形成、检索与归档策略。

## “存着”不等于“每次都会说出来”

长期记忆的作用是给对话提供可能需要的背景。

一条记忆存在于数据库中，不代表每次聊天都会被放进上下文；只有和当前内容相关、并通过检索与筛选的部分才会参与本轮对话。

这样可以减少无关信息反复出现，也能控制上下文长度。

## 记忆原子

Nori 会把部分长期记忆整理成更细的事实单元，例如偏好、客观事实、关系、计划和身份信息。

这些条目可以有自己的重要度、置信度和状态，用于后续检索与整理。

普通用户不需要手动维护所有原子；它们主要用于查看 Nori 为什么会记住某件事，以及需要时纠正内容。

## Embedding 与检索

如果启用了向量检索，可以在 AI 设置中为记忆单独配置 Embedding 服务。

关键词检索和向量检索会共同帮助 Nori 找到和当前对话有关的内容。更换 Embedding 模型后，如果需要重新建立索引，可以从记忆管理中执行对应操作。

## 后台整理

Nori 可以在后台整理记忆，例如合并重复内容、更新状态或把不再活跃的内容移入归档。

这些行为由记忆设置控制。想保持更保守的记忆方式时，可以降低或关闭相关自动整理选项。

## 导入与导出

导入不会在选中文件后立刻写入。

Nori 会先生成预览，再让你选择遇到冲突时怎样处理。确认后才会真正应用。

导出内容适合备份和迁移，但仍建议同时保留整个 `data` 目录作为完整备份。
