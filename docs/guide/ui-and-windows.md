# 界面与窗口行为

Nori 看起来像一个桌面宠物，但实际会把“桌宠显示”和“控制界面”分开处理。这样做可以让 Live2D 窗口保持透明，同时让聊天、设置和语音功能在主控制台中稳定运行。

## 你会看到哪些窗口

Nori 有四类固定窗口：

- **首次运行向导**：第一次使用时出现，完成基础设置后就会关闭。
- **初始化界面**：启动过程中短暂显示，用来等待必要组件准备完成。
- **主控制台**：聊天、设置、模型、记忆、插件和诊断等功能都在这里。
- **桌宠窗口**：单独显示 Live2D 角色。

插件还可以创建自己的独立窗口，这类窗口不属于上面四个固定窗口。

## 为什么关掉主控制台后 Nori 还在

主控制台右上角的关闭操作通常会隐藏窗口，不会直接退出整个 Nori。

这样可以让：

- 桌宠继续显示
- 语音播放状态继续保留
- 托盘入口继续可用
- 后台提醒等功能继续运行

如果想完全退出 Nori，应使用托盘或主界面提供的退出入口。

## 主控制台为什么和语音有关

当前版本把语音播放集中在主控制台中处理。即使控制台窗口被隐藏，只要 Nori 进程还在运行，语音播放和口型联动就可以继续工作。

如果强制结束主进程，正在进行的语音、提醒和后台任务也会一起停止。

## 桌宠窗口为什么是单独的

桌宠使用独立窗口显示 Live2D，这样可以更好地处理：

- 透明背景
- 置顶显示
- 拖动
- 点击穿透
- 全局或窗口内鼠标跟随

这些能力和普通网页窗口差别很大，所以没有和主控制台塞在同一个窗口里。

## 点击穿透为什么不同平台不一样

Windows、X11、Wayland 和 macOS 对透明窗口的输入处理方式不同。

Windows 当前已经恢复模型区域与空白区域的点击穿透逻辑。Linux X11 也可以使用输入区域控制；Wayland 受协议限制，可能退化为整窗可点击。macOS 使用系统对应的鼠标忽略方式。

详情见 [跨平台支持与能力差异](../operations/platform-matrix.md)。

## 系统托盘

在支持托盘的平台上，可以从托盘快速：

- 打开主控制台
- 显示或隐藏桌宠
- 退出 Nori

Linux 的托盘支持取决于桌面环境。如果托盘不可用，Nori 会在主界面保留可操作入口。

## 为什么 Nori 会访问 127.0.0.1

主控制台会通过本机回环地址加载自己的界面资源、本地模型和临时音频。

这类地址只在本机使用。Nori 还会限制访问来源，并为内部资源使用随机路径，避免把本地内容当成普通公开网站暴露出去。

## 插件窗口与聊天卡片

NPS 2.0 插件可以提供自己的独立窗口，也可以把 `web/card.html` 作为聊天卡片显示在主控制台中。

聊天卡片由插件自己负责界面和交互，主程序只提供统一的显示位置和调用通道。
