# 安装与使用插件

Nori 可以通过 `.noripack` 安装本地插件。当前插件主要用于给 Nori 增加新的本机动作，并让这些动作在启用后可以交给 AI 调用。

::: warning 插件是受信任的本机扩展
插件会作为 .NET 代码在 Nori 进程中运行，并不处在真正的安全沙箱里。只安装来源可信、或者你已经检查过的插件。
:::

## 安装插件

打开 **设置 → 插件**，选择本地 `.noripack` 文件：

<UiPluginsPreview />

第一次安装时，Nori 会提示插件属于受信任的进程内扩展。

新安装的插件默认保持关闭状态。确认来源和用途后，再手动启用即可。

## 插件现在可以做什么

当前 Plugin API 2.0 的主要用户可见能力是 **插件动作**。

启用后的插件可以注册动作，Nori 会把这些动作加入可用工具，让 AI 在合适的时候调用。

::: info 当前没有插件页面
当前宿主没有向第三方插件开放自定义窗口、WebView 页面或聊天卡片。旧文档中关于“插件窗口”和“聊天卡片”的描述已经不适用于现在的实现。
:::

## 启用、禁用和卸载

插件可以在设置中启用、禁用或卸载。

如果插件在运行中无法完整释放，Nori 会把相关操作标记为需要重启，再在下次启动时完成。

卸载时可以选择是否同时删除插件自己的数据。

## 插件导致 Nori 无法正常启动

可以使用安全模式：

```text
--safe-mode
```

安全模式不会加载第三方插件，但仍可以查看插件列表，并禁用或卸载有问题的插件。

详情见 [安全模式](../operations/safe-mode.md)。

## 插件开发

Plugin API 当前为 **2.0**。公开的 `Nori.PluginSDK` NuGet 包最新版本为 **2.2.0**，目标框架为 .NET 10：

```bash
dotnet add package Nori.PluginSDK --version 2.2.0
```

SDK 只提供编译所需的公开合同；运行时由 Nori Desktop 自己提供，因此插件包里不应该携带 `Nori.PluginRuntime.dll`。

SDK 仓库位于 [MF-Dust/Nori.PluginSDK](https://github.com/MF-Dust/Nori.PluginSDK)。

## 当前还没有什么

目前没有：

- 联网插件市场
- 自动下载或自动更新第三方插件
- 插件签名商店
- WASM 或独立进程沙箱
- 第三方插件页面、窗口或聊天卡片

这些边界比“看起来能不能加载一个 DLL”更重要，也更能说明当前插件系统适合拿来做什么。
