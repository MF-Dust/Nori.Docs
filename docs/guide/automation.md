# 浏览器与桌面自动化

Nori Desktop Pet 内置了一套严格受控的**浏览器与桌面自动化执行子系统**，允许伴侣在获得用户授权的前提下协助完成网页检索、表单处理与自动化工作流。

---

## 1. 运行前提与平台支持

::: warning 严格的平台与运行约束
1. **仅限 Windows x64 平台**：自动化子系统目前仅在 Windows 上完成功能适配与安全沙箱验证。
2. **依赖已安装的 Microsoft Edge 浏览器**：
   - 系统利用底层 Playwright 直连本机已安装的 `msedge` 官方稳定版渠道。
   - **绝不随发布包捆绑或在后台下载 Chromium 浏览器**，保持系统纯净。
3. **临时隔离 Profile 运行**：
   - 每次自动化任务均使用独立的临时用户目录，不会窃取或污染你日常 Edge 浏览器的 Cookies、历史记录或登录状态。
:::

---

## 2. 安全策略与 Fail-Closed 原则

自动化属于高度敏感的高特权功能，Nori 实施了极为苛刻的安全准则：

- **默认全局关闭**：安装后所有自动化总开关与桌面/浏览器开关默认均为 `false`，必须由用户在 **「设置」→「自动化」** 中手动显式开启。
- **高危动作人工在环审批**：大模型生成的填写、点击、跳转等指令在下发前均需在主界面的 **操作抽屉（Operation Drawer）** 中呈现详情并由用户人工审批。
- **安全模式硬禁用**：在 `--safe-mode` 下，自动化后端直接抛出异常并拒绝执行任何指令。
- **全量审计日志 (`automation_audit_list`)**：每次自动化调用的动作类型、参数、执行耗时与截图均记录在审计流中，供随时回溯检查。

## 3. 自动化任务调度与控制

<UiAutomationPreview />

- **任务启动与取消**：当 Agent 启动自动化任务时，主控制台右侧会滑出 **任务状态卡片（Automation Task Card）**，实时呈现当前执行步骤。
- **一键强行终止 (`automation_stop_all`)**：遇到任何非预期状态时，可在控制台随时点击「停止全部任务」，宿主会立即释放 Playwright 实例并强制关闭对应子进程。
