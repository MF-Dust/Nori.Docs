# 浏览器与桌面自动化

Nori 可以在获得授权后协助完成部分浏览器和桌面操作。自动化涉及更高的本机权限，因此默认关闭，并且会受到平台和审批规则限制。

## 当前平台支持

目前浏览器自动化只在 **Windows x64** 上提供完整路径，并使用系统已经安装的 Microsoft Edge。

Nori 不会为了自动化在后台额外下载一套 Chromium。

每次任务会使用独立的临时浏览器资料目录，不会直接复用你日常 Edge 的 Cookie、历史记录和登录状态。

## 怎样开启

进入 **设置 → 自动化**：

<UiAutomationPreview />

可以分别控制：

- 自动化总开关
- 浏览器自动化
- 当前环境支持的桌面能力

不需要自动化时，保持关闭即可，不会影响普通聊天和桌面伴侣功能。

## 哪些操作需要确认

涉及填写、点击、跳转或其他可能改变外部状态的操作时，Nori 会把待执行内容交给审批界面。

只有在你同意后，相应操作才会继续。拒绝后，当前操作会取消。

## 怎样停止正在运行的任务

自动化设置和任务界面提供停止入口。出现页面状态不对、任务走错或你临时改变主意时，可以终止当前自动化任务。

## 安全模式

`--safe-mode` 会关闭自动化执行能力。这样排查启动或配置问题时，不会同时拉起浏览器任务或外部操作。

## 审计记录

Nori 会保留自动化操作所需的审计信息，方便查看最近发生了什么。

审计记录用于排障和确认行为，不代表会保存你的整个浏览器资料或日常浏览历史。
